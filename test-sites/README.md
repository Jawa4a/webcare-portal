# Контролируемые тестовые сайты

Каталог содержит небольшие локальные HTTP-сайты с заранее известными характеристиками:

- `/healthy/` — корректные `title`, description, H1, canonical и `alt`;
- `/issues/` — отсутствующие метаданные, `noindex`, несколько H1, изображение без `alt`, битая ссылка и редирект;
- `/redirect` — контролируемый HTTP 302 на `/issues/`;
- неизвестный путь — стандартный HTTP 404.

Эти сайты предназначены только для автоматических и демонстрационных проверок механизма аудита и не должны публиковаться в интернет.

Контур запускается файлом `compose.test.yaml`. Только в нём включён `AUDIT_ALLOW_PRIVATE_ADDRESSES=true`, поскольку тестовый Nginx расположен во внутренней Docker-сети. В обычном приложении этот параметр всегда должен оставаться `false`.
