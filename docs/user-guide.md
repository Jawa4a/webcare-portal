# Руководство пользователя

## Роли

- `ADMIN`: все операции и просмотр команды;
- `SPECIALIST`: сайты, запуски аудитов и задачи обслуживания;
- `VIEWER`: только просмотр панели, результатов и задач.

Backend проверяет роль для каждого изменяющего запроса; скрытая кнопка не является единственной защитой.

## Вход в демо

На странице входа кнопки «Администратор», «Специалист» и «Наблюдатель» заполняют публичные данные соответствующей роли. После выбора роли нажмите «Войти». Demo-режим восстанавливает эти пароли при запуске backend, поэтому кнопки работают и с ранее созданным томом PostgreSQL.

## Добавление сайта

1. Откройте «Сайты» и нажмите «Добавить сайт».
2. Укажите название и публичный HTTP/HTTPS URL.
3. Задайте максимум страниц и глубину обхода.
4. Сохраните сайт.

Локальные, частные, служебные адреса, credentials в URL, нестандартные порты и повтор домена отклоняются.

## Аудит

В реестре сайтов нажмите «Запустить аудит». Запуск выполняется в фоне; страницу можно закрыть или перейти в другой раздел. Состояния: в очереди, выполняется, завершён, ошибка.

В результатах доступны:

- оценка от 0 до 100;
- проверенные страницы и HTTP-показатели;
- важность, код правила, описание и рекомендация;
- фильтры по важности, изменению, коду и тексту.

## Сравнение

Портал сравнивает два последних завершённых аудита сайта:

- новая проблема присутствует только в последнем;
- продолжающаяся присутствует в обоих;
- исправленная осталась только в предыдущем.

Ошибочные и незавершённые запуски не включаются в пару сравнения.

## Задачи обслуживания

Из карточки проблемы создайте задачу. Затем в разделе «Задачи» можно изменить название, описание, приоритет, ответственного, срок и статус.

Статусы: открыта, в работе, выполнена, отменена. Каждая смена статуса сохраняет автора, время и комментарий. Продолжающаяся проблема использует существующую задачу и не создаёт дубликат.

## Типичные состояния

- пустой реестр: сначала добавьте сайт;
- аудит завершён с ошибкой: проверьте публичную доступность стартового URL;
- нет результатов по фильтру: сбросьте фильтры;
- действие недоступно: текущая роль имеет доступ только на чтение либо сайт неактивен.
